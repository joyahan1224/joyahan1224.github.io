ID Photo Maker

Condicions d'ús

Versió 8 · Actualitzat 2026-11-25

com.joyahan.idphoto

1. El vostre ús de l'aplicació

Una persona desenvolupadora que publica a Google Play amb el nom de desenvolupador Joya Han ofereix ID Photo Maker per preparar i editar fotos. Utilitzeu imatges de les quals sigueu titulars o que estigueu legalment autoritzats a utilitzar. Respecteu la privadesa, els drets d'imatge i la llei aplicable, inclosos els permisos exigits per a fotos d'infants. No utilitzeu l'aplicació per crear materials d'identitat il·legals o enganyosos.

2. Comproveu el resultat i les normes dels documents

Comproveu els requisits vigents de l'autoritat emissora abans de presentar la foto. Les mides, els exemples i les eines d'edició no garanteixen l'acceptació. Algunes autoritats restringeixen el retoc. Conserveu la foto original i reviseu raonablement el rostre, la roba, el fons, les vores i les dimensions d'impressió finals. L'aplicació no està vinculada a cap govern ni emissor de documents.

3. Funcions i serveis de tercers

L'aplicació actual és gratuïta, inclou publicitat i no requereix compte, compra ni subscripció. Les futures funcions de pagament presentaran les seves condicions per separat. Les destinacions d'exportació i els serveis externs tenen les seves pròpies condicions. El programari i els materials inclosos continuen subjectes a les llicències aplicables; utilitzar l'aplicació no transfereix la propietat de les vostres fotos.

4. Els vostres drets i contacte

Aquestes condicions no exclouen ni limiten drets dels consumidors o responsabilitats que la llei aplicable no ens permeti excloure o limitar. Per a qüestions sobre l'aplicació o aquestes condicions, contacteu amb liusuiyun713@gmail.com. Us informarem dels canvis substancials, amb qualsevol acceptació que exigeixi la llei.
