ID Photo Maker

隱私權政策

版本 8 · 更新於 2026-11-25

com.joyahan.idphoto

1. 營運者與聯絡方式

ID Photo Maker（應用程式套件名稱 com.joyahan.idphoto）由個人開發者營運，其 Google Play 開發者名稱為 Joya Han。本政策說明本應用程式及本政策網站如何處理資訊。如有隱私問題或需行使相關權利，請聯絡 liusuiyun713@gmail.com。

2. 照片與裝置內處理

照片編輯、臉部定位和背景移除均在您的裝置上進行。照片不會上傳至編輯服務，也不會傳送給廣告商。臉部定位用於協助照片構圖，不是雲端身分辨識服務。

Android 相片挑選工具允許應用程式存取您選取的照片。較舊的裝置可能會要求圖片存取權限，以顯示本機相簿。拍照時會要求相機權限；只有您確認使用的拍攝照片才會用於編輯。您可以拒絕權限，或在 Android 設定中撤銷權限，這可能會限制相應功能。

3. 本機檔案與偏好設定

私人作品和草稿可能保留原始輸入檔案、包含透明資訊的影像圖層及編輯紀錄，以便您繼續編輯。輸入檔案會逐位元組複製，可能保留內嵌的中繼資料，包括來源檔案中已有的位置資訊。這些檔案存放於應用程式專用、設定為排除 Android 應用程式備份的儲存空間。較舊的作品可能只有完成的影像。

應用程式也會在本機儲存歷史紀錄、偏好設定、說明版本及確認時間。本機診斷資訊有助於調查故障；應用程式不會自動傳送這些本機記錄檔。

4. 您匯出或分享的副本

儲存至相簿、匯出檔案或 PDF、分享及列印會建立獨立副本，或將副本傳送至您選擇的目的地，不會覆寫原始照片。接收的應用程式、儲存服務供應商和列印服務會依照各自的政策處理這些副本。您的相簿或目的地可能將副本同步至雲端。刪除應用程式的私人資料不會移除這些副本；請在各個目的地管理它們。

5. Google 設定與廣告服務

您確認應用程式說明後，Firebase Remote Config 和 Firebase Installations 會連線至 Google 以取得廣告設定，即使廣告已停用也會進行連線。傳送的資訊包括 Firebase 安裝識別碼、安裝驗證資訊、裝置地區設定中的國家或地區代碼，以及語言、時區、平台、作業系統、應用程式識別碼、應用程式及建構版本、套件名稱和 SDK 版本資訊。地區設定中的地區代碼並非 GPS 位置。

廣告服務執行時，Google AdMob 可能處理 IP 位址、由 IP 推估的大致位置、應用程式及廣告互動（例如應用程式啟動、廣告點擊和影片觀看）、效能與診斷資料，以及適用的識別碼，例如 Android 廣告識別碼和 App Set ID。Google 會將這些資訊用於廣告、分析及詐欺防範。這些 SDK 連線在傳輸過程中使用 TLS 加密。

Google UMP 會管理適用地區的隱私選項，並處理這些選擇，以及請求和顯示同意表單所需的應用程式、裝置及請求資訊。本版本不含帳號、應用程式內購買、訂閱、Firebase Analytics、Firebase Crashlytics 或 Meta SDK。但 AdMob 本身仍會進行分析處理。Google 的資訊處理與保留方式見其政策：https://policies.google.com/privacy

6. 您的廣告選擇

確認本政策不代表同意個人化廣告。在適用情況下，您可以透過 Google 同意表單或「設定 > 廣告隱私選項」作出或撤回選擇。拒絕個人化廣告不會停止所有網路請求：設定、同意管理及獲准提供的廣告仍可能需要處理資料。您也可以查看 Android 的廣告隱私控制選項。法律要求取得同意的資料處理，必須另行取得該同意，並允許撤回。

7. 意見回饋與網站造訪

只有您選擇傳送時，才會傳送意見回饋。內容可能包括您的電子郵件地址、訊息及您選取的應用程式或裝置資訊。照片和本機記錄檔不會自動附加。請在傳送前檢查訊息和所有附件。我們使用往來訊息回覆和解決問題，僅在該目的及適用法律義務所需的期間內保留。

我們的聯絡信箱使用 Google 的 Gmail 服務。您寄送電子郵件給我們時，Google 會處理寄件者地址、訊息、您附上的檔案，以及傳遞和儲存郵件所需的資訊。您選用的寄件服務也會依其自身政策處理郵件。請參閱 https://policies.google.com/privacy

對於由我們控制的往來訊息，在適用法律允許的範圍內，我們以回覆詢問及解決問題的合法利益作為處理依據。處理法定權利請求或依法保留資訊時，我們依據適用的法律義務。需要同意的處理，我們會另行取得同意，您也可以撤回。這些依據不會取代廣告、存取您裝置上的資訊或其他 SDK 處理依法所需的同意。

本政策網站由 GitHub 提供的 GitHub Pages 託管。造訪時，GitHub 可能接收 IP 位址、請求時間及瀏覽器資訊等一般存取資訊，以提供及保護網站服務。這些網頁不包含分析指令碼、廣告、遠端字型或圖片。GitHub 隱私權聲明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

8. 保留與刪除

私人作品和草稿會保留至您刪除為止。清除應用程式資料或解除安裝會移除應用程式的私人資料，包括本機偏好設定和確認紀錄。請先保存需要的原始檔案和匯出檔案。

編輯、拍攝和列印的暫存檔案會在正常流程中清理；流程中斷或當機可能延後清理。分享快取檔案在七天後符合移除條件，但清理會在您下次分享時才執行，因此檔案可能保留更久。Google 依各項服務適用的規則保留其服務儲存的資訊；刪除應用程式不一定會刪除這些資訊。另請參閱 Firebase 隱私資訊：https://firebase.google.com/support/privacy

9. 隱私權利與請求

依適用法律，您可能享有請求存取、更正、刪除、限制處理、資料可攜、反對處理、撤回同意，以及向有管轄權的隱私監管機關申訴的權利。請聯絡 liusuiyun713@gmail.com。我們可能要求提供適度資訊，以核實及處理您的請求，並遵守適用的法律要求。撤回同意不影響先前合法處理的效力。

我們無法遠端取得僅儲存在您裝置上的照片。我們可以說明本機刪除方式，並處理由我們控制的資訊。對於 Google 持有的資訊，我們可以指引您使用相關控制選項，或在可行情況下協助轉交請求；但無法承諾刪除 Google 持有的全部資料。

10. 跨境處理

Google、電子郵件及網站託管服務可能在您所在國家以外處理資訊。適用保障取決於服務和法律，可能包括合約安排或其他獲認可的傳輸機制。對於由我們負責的處理，您可聯絡我們了解可提供的資訊；Google 的政策說明其跨境處理方式。

11. 使用對象與他人的照片

本應用程式以成年人為使用對象，並非針對兒童。成年人只有在具備必要的家長、監護人或其他合法權限時，才可以為兒童製作照片。如果您認為兒童在未獲適當授權的情況下向我們提供了資訊，請聯絡我們，以便評估請求並採取適當措施。

使用他人的照片，包括兒童照片，必須取得適用法律要求的授權，以及所需的家長或監護人許可。

12. 本政策的變更

相關處理方式變更時，我們會更新本政策並標明更新版本。重大變更將以醒目方式通知。在必要情況下，我們會在受影響的處理開始前重新徵求同意。僅開啟本政策不會變更您已儲存的選擇。
