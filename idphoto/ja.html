ID Photo Maker

プライバシーポリシー

バージョン 8 · 更新日 2026-11-25

com.joyahan.idphoto

1. アプリの運営者

ID Photo Maker（パッケージ名 com.joyahan.idphoto）は、Google Play のデベロッパー名 Joya Han で公開する個人開発者が運営しています。本ポリシーは、本アプリおよび本ポリシーのウェブサイトにおける情報の取扱いを説明するものです。プライバシーやお客様の権利に関するお問い合わせは liusuiyun713@gmail.com までご連絡ください。

2. 写真と端末内での処理

写真の編集、顔の位置の検出、背景の除去は、お客様の端末内で実行されます。写真を編集サービスにアップロードしたり、広告主に送信したりすることはありません。顔の位置の検出は写真の構図を整えるためのものであり、クラウド上で本人を識別するサービスではありません。

Android の写真選択ツールにより、選択された写真へのアクセスが許可されます。古い端末では、端末内のアルバムを表示するために画像へのアクセス権限を求める場合があります。カメラへのアクセス権限は撮影時に求められ、お客様が使用を確定した撮影画像だけが編集に使用されます。権限を拒否したり、Android の設定で取り消したりできますが、対応する機能が制限される場合があります。

3. 端末内のファイルと設定

アプリ専用領域の作品や下書きには、編集を再開できるよう、元の入力ファイル、透明度を含む画像レイヤー、編集履歴が保存される場合があります。入力ファイルはバイト単位でそのままコピーされ、元のファイルに位置情報などのメタデータが埋め込まれている場合、それらも保持されることがあります。これらのファイルは、Android のアプリバックアップから除外するよう設定されたアプリ専用ストレージに保存されます。古い作品には完成画像のみが含まれる場合があります。

本アプリは、履歴、設定、説明のバージョン、確認日時も端末内に保存します。端末内の診断情報は不具合の調査に役立ちますが、本アプリがこれらのローカルログを自動送信することはありません。

4. 書き出しや共有で作成するコピー

ギャラリーへの保存、ファイルや PDF の書き出し、共有、印刷を行うと、元の写真を上書きせずに独立したコピーが作成されるか、お客様が選択した送信先にコピーが渡されます。受信側のアプリ、ストレージ提供者、印刷サービスは、それぞれのポリシーに従ってコピーを取り扱います。ギャラリーや保存先がコピーをクラウドに同期する場合があります。アプリ専用データを削除しても、これらのコピーは削除されません。各保存先で管理してください。

5. Google の設定取得サービスと広告サービス

お客様がアプリの説明を確認した後、Firebase Remote Config と Firebase Installations は、広告が無効になっている場合も含め、広告設定を取得するために Google に接続します。送信される情報には、Firebase のインストール識別子、インストール認証情報、端末のロケール設定に基づく国または地域コード、言語、タイムゾーン、プラットフォーム、オペレーティングシステム、アプリ識別子、アプリとビルドのバージョン、パッケージ名、SDK のバージョン情報が含まれます。ロケールの地域コードは GPS による位置情報ではありません。

広告サービスの動作中、Google AdMob は、IP アドレス、IP から推定されるおおよその位置、アプリや広告に関する操作（アプリの起動、広告のクリック、動画の視聴など）、パフォーマンスおよび診断データ、ならびに Android 広告 ID や App Set ID などの該当する識別子を処理する場合があります。Google はこれらの情報を広告、分析、不正防止に使用します。これらの SDK 接続では、通信中に TLS 暗号化を使用します。

Google UMP は、該当する地域のプライバシー選択を管理し、その選択内容と、同意フォームの要求・表示に必要なアプリ、端末、リクエストの情報を処理します。本バージョンには、アカウント、アプリ内購入、サブスクリプション、Firebase Analytics、Firebase Crashlytics、Meta SDK はありません。ただし、AdMob 自体による分析処理は行われます。Google による情報の取扱いと保持については、同社のポリシーをご覧ください：https://policies.google.com/privacy

6. 広告に関する選択

本ポリシーの確認は、パーソナライズ広告への同意を意味しません。該当する場合、Google の同意フォームまたは「設定 > 広告のプライバシー設定」から選択を行い、または撤回できます。パーソナライズ広告を拒否しても、すべてのネットワークリクエストが停止するわけではありません。設定取得、同意管理、許可された広告のために、引き続きデータ処理が必要になる場合があります。Android の広告プライバシー設定も確認できます。法律上、処理に同意が必要な場合、その同意は別途取得されなければならず、撤回することができます。

7. フィードバックとウェブサイトの閲覧

フィードバックは、お客様が送信を選択したときにのみ送信されます。メールアドレス、メッセージ、選択したアプリや端末の情報が含まれる場合があります。写真や端末内のログは自動添付されません。送信前にメッセージと添付ファイルを確認してください。やり取りの内容は返信や問題の解決に使用し、その目的および適用される法的義務のために必要な期間だけ保持します。

当方の連絡用メールボックスには、Google のサービスである Gmail を使用しています。お客様が当方にメールを送信すると、Google は送信者のアドレス、本文、お客様が含めた添付ファイル、およびメールの配信・保存に必要な情報を処理します。お客様が選択した送信サービスも、独自のポリシーに従ってメールを取り扱います。詳しくは https://policies.google.com/privacy をご覧ください。

当方が管理するやり取りについては、適用法で認められる場合、お問い合わせへの回答と問題の解決という当方の正当な利益に基づいて処理します。法定の権利に関する請求への対応や、法律で求められる情報の保持については、該当する法的義務に基づいて処理します。処理に同意が必要な場合は別途取得し、お客様はその同意を撤回できます。これらの根拠は、広告、端末上の情報へのアクセス、その他の SDK 処理について法律上必要な同意に代わるものではありません。

本ポリシーのウェブサイトは、GitHub が提供する GitHub Pages でホストされています。閲覧時に GitHub は、ウェブサイトの提供と保護のため、IP アドレス、リクエスト時刻、ブラウザー情報などの一般的なアクセス情報を受け取る場合があります。これらのページには、分析スクリプト、広告、外部から読み込むフォントや画像は含まれていません。GitHub のプライバシーステートメントをご覧ください：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

8. 保持と削除

アプリ専用領域の作品と下書きは、お客様が削除するまで残ります。アプリのデータを消去したり、アンインストールしたりすると、端末内の設定や確認記録を含むアプリ専用データが削除されます。必要な元画像や書き出したファイルは、事前に保存してください。

編集、撮影、印刷の一時ファイルは通常の操作の過程で削除されますが、中断やクラッシュにより削除が遅れる場合があります。共有用キャッシュファイルは七日経過すると削除対象になりますが、削除処理は次回の共有時に実行されるため、それより長く残る場合があります。Google は各サービスに適用されるルールに従って、そのサービスに保存された情報を保持します。アプリを削除しても、それらの情報が必ず削除されるわけではありません。Firebase のプライバシー情報もご覧ください：https://firebase.google.com/support/privacy

本アプリは成人を対象としており、子どもを対象としたものではありません。成人が子どもの写真を作成できるのは、必要な親権、後見上の権限、その他の法的権限を有する場合に限られます。子どもが適切な権限なしに当方へ情報を提供したと思われる場合は、請求を評価して適切な措置を取れるよう、当方までご連絡ください。
