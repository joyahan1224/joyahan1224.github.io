1. ผู้ดำเนินการแอป

ID Photo Maker (ชื่อแพ็กเกจ com.joyahan.idphoto) ดำเนินการโดยผู้พัฒนาที่เป็นบุคคลธรรมดา ซึ่งเผยแพร่ภายใต้ชื่อนักพัฒนาใน Google Play ว่า Joya Han นโยบายนี้อธิบายวิธีที่แอปและเว็บไซต์นโยบายนี้จัดการข้อมูล หากมีคำถามเกี่ยวกับความเป็นส่วนตัวหรือสิทธิของคุณ โปรดติดต่อ joyahan1224@gmail.com

2. รูปภาพและการประมวลผลบนอุปกรณ์

การแก้ไขรูปภาพ การระบุตำแหน่งใบหน้า และการลบพื้นหลังทำงานบนอุปกรณ์ของคุณ รูปภาพจะไม่ถูกอัปโหลดไปยังบริการแก้ไขรูปภาพหรือส่งให้ผู้ลงโฆษณา การระบุตำแหน่งใบหน้าช่วยจัดองค์ประกอบภาพ ไม่ใช่บริการจดจำตัวบุคคลบนคลาวด์

เครื่องมือเลือกรูปภาพของ Android ให้สิทธิ์เข้าถึงรูปภาพที่เลือก อุปกรณ์รุ่นเก่าอาจขอสิทธิ์เข้าถึงรูปภาพเพื่อแสดงอัลบั้มในเครื่อง ระบบจะขอสิทธิ์ใช้กล้องเมื่อคุณถ่ายรูป และจะใช้แก้ไขเฉพาะภาพถ่ายที่คุณยืนยันเท่านั้น คุณสามารถปฏิเสธหรือเพิกถอนสิทธิ์ในการตั้งค่า Android ซึ่งอาจทำให้ฟีเจอร์ที่เกี่ยวข้องใช้งานได้จำกัด

3. ไฟล์ในเครื่องและค่ากำหนด

ผลงานส่วนตัวและฉบับร่างอาจเก็บไฟล์ต้นฉบับที่นำเข้า ชั้นภาพรวมถึงข้อมูลความโปร่งใส และประวัติการแก้ไข เพื่อให้คุณกลับมาแก้ไขต่อได้ ไฟล์นำเข้าจะถูกคัดลอกแบบไบต์ต่อไบต์ และอาจคงข้อมูลเมตาที่ฝังไว้ รวมถึงตำแหน่งที่ตั้งหากมีอยู่ในต้นฉบับ ไฟล์เหล่านี้ใช้พื้นที่จัดเก็บส่วนตัวของแอปที่กำหนดให้ไม่รวมอยู่ในการสำรองข้อมูลแอปของ Android ผลงานเก่าอาจมีเพียงภาพที่เสร็จแล้ว

แอปยังเก็บประวัติ ค่ากำหนด เวอร์ชันของคำชี้แจง และเวลาที่ยืนยันไว้ในเครื่อง ข้อมูลวินิจฉัยในเครื่องช่วยตรวจสอบข้อผิดพลาด แอปจะไม่ส่งบันทึกในเครื่องเหล่านี้โดยอัตโนมัติ

4. สำเนาที่คุณส่งออกหรือแชร์

การบันทึกลงแกลเลอรี การส่งออกไฟล์หรือ PDF การแชร์ และการพิมพ์ จะสร้างหรือส่งสำเนาแยกต่างหากไปยังปลายทางที่คุณเลือก โดยไม่เขียนทับรูปภาพต้นฉบับ แอปที่รับข้อมูล ผู้ให้บริการพื้นที่จัดเก็บ และบริการพิมพ์จะจัดการสำเนาเหล่านั้นตามนโยบายของตน แกลเลอรีหรือปลายทางของคุณอาจซิงค์สำเนาไปยังคลาวด์ การลบข้อมูลส่วนตัวของแอปไม่ได้ลบสำเนาเหล่านี้ โปรดจัดการสำเนาที่ปลายทางแต่ละแห่ง

5. บริการกำหนดค่าและโฆษณาของ Google

หลังจากคุณยืนยันคำชี้แจงของแอปแล้ว Firebase Remote Config และ Firebase Installations จะเชื่อมต่อกับ Google เพื่อเรียกการตั้งค่าโฆษณา รวมถึงในกรณีที่ปิดโฆษณาอยู่ด้วย บริการเหล่านี้ส่งตัวระบุการติดตั้ง Firebase ข้อมูลยืนยันตัวตนของการติดตั้ง รหัสประเทศหรือภูมิภาคจากการตั้งค่าภาษาและภูมิภาคของอุปกรณ์ ภาษา เขตเวลา แพลตฟอร์ม ระบบปฏิบัติการ ตัวระบุแอป เวอร์ชันแอปและบิลด์ ชื่อแพ็กเกจ และข้อมูลเวอร์ชัน SDK รหัสภูมิภาคจากการตั้งค่าภาษาและภูมิภาคไม่ใช่ตำแหน่ง GPS

เมื่อบริการโฆษณาทำงาน Google AdMob อาจประมวลผลที่อยู่ IP ตำแหน่งโดยประมาณที่อนุมานจาก IP การโต้ตอบกับแอปและโฆษณา (เช่น การเปิดแอป การคลิกโฆษณา และการดูวิดีโอ) ข้อมูลประสิทธิภาพและการวินิจฉัย รวมถึงตัวระบุที่เกี่ยวข้อง เช่น รหัสโฆษณา Android และ App Set ID Google ใช้ข้อมูลนี้เพื่อการโฆษณา การวิเคราะห์ และการป้องกันการฉ้อโกง การเชื่อมต่อ SDK เหล่านี้ใช้การเข้ารหัส TLS ระหว่างการรับส่งข้อมูล

Google UMP จัดการตัวเลือกความเป็นส่วนตัวที่ใช้บังคับในแต่ละภูมิภาค และประมวลผลตัวเลือกเหล่านั้นร่วมกับข้อมูลแอป อุปกรณ์ และคำขอที่จำเป็นต่อการขอและแสดงแบบฟอร์มความยินยอม เวอร์ชันนี้ไม่มีบัญชี การซื้อในแอป การสมัครสมาชิก Firebase Analytics, Firebase Crashlytics หรือ Meta SDK อย่างไรก็ตาม AdMob ยังคงประมวลผลเพื่อการวิเคราะห์ของตนเอง นโยบายของ Google อธิบายวิธีจัดการและเก็บรักษาข้อมูล: https://policies.google.com/privacy

6. ตัวเลือกด้านโฆษณาของคุณ

การยืนยันนโยบายนี้ไม่ใช่การให้ความยินยอมต่อโฆษณาที่ปรับเปลี่ยนให้เหมาะกับแต่ละบุคคล ในกรณีที่เกี่ยวข้อง คุณสามารถกำหนดหรือถอนตัวเลือกผ่านแบบฟอร์มความยินยอมของ Google หรือ การตั้งค่า > ตัวเลือกความเป็นส่วนตัวของโฆษณา การปฏิเสธโฆษณาที่ปรับเปลี่ยนให้เหมาะกับแต่ละบุคคลไม่ได้หยุดคำขอเครือข่ายทั้งหมด การกำหนดค่า การจัดการความยินยอม และโฆษณาที่อนุญาตอาจยังต้องประมวลผลข้อมูล คุณยังสามารถตรวจดูการควบคุมความเป็นส่วนตัวของโฆษณาใน Android ได้ หากกฎหมายกำหนดให้ต้องได้รับความยินยอมในการประมวลผล จะต้องขอความยินยอมนั้นแยกต่างหากและสามารถถอนความยินยอมได้

7. ข้อเสนอแนะและการเยี่ยมชมเว็บไซต์

ข้อเสนอแนะจะถูกส่งเมื่อคุณเลือกส่งเท่านั้น โดยอาจรวมที่อยู่อีเมล ข้อความ และข้อมูลแอปหรืออุปกรณ์ที่คุณเลือก รูปภาพและบันทึกในเครื่องจะไม่ถูกแนบโดยอัตโนมัติ โปรดตรวจสอบข้อความและไฟล์แนบก่อนส่ง เราใช้การติดต่อโต้ตอบเพื่อให้คำตอบและแก้ไขปัญหา และเก็บไว้เพียงเท่าที่จำเป็นสำหรับวัตถุประสงค์ดังกล่าวและหน้าที่ตามกฎหมายที่ใช้บังคับ

กล่องจดหมายสำหรับติดต่อเราใช้ Gmail ซึ่งเป็นบริการของ Google เมื่อคุณส่งอีเมลหาเรา Google จะประมวลผลที่อยู่ผู้ส่ง ข้อความ ไฟล์แนบที่คุณใส่มา และข้อมูลที่จำเป็นต่อการนำส่งและจัดเก็บอีเมล บริการส่งอีเมลที่คุณเลือกก็จัดการอีเมลตามนโยบายของตนเช่นกัน ดู https://policies.google.com/privacy

สำหรับการติดต่อโต้ตอบที่เราควบคุม ในกรณีที่กฎหมายที่ใช้บังคับอนุญาต เราอาศัยประโยชน์โดยชอบด้วยกฎหมายในการตอบข้อซักถามและแก้ไขปัญหา เราอาศัยหน้าที่ตามกฎหมายที่เกี่ยวข้องเมื่อจัดการคำขอใช้สิทธิตามกฎหมายหรือเก็บข้อมูลตามที่กฎหมายกำหนด หากการประมวลผลต้องได้รับความยินยอม เราจะขอแยกต่างหากและคุณสามารถถอนความยินยอมได้ ฐานเหล่านี้ไม่ใช้แทนความยินยอมใด ๆ ที่กฎหมายกำหนดสำหรับการโฆษณา การเข้าถึงข้อมูลบนอุปกรณ์ของคุณ หรือการประมวลผลอื่นของ SDK

เว็บไซต์นโยบายนี้โฮสต์บน GitHub Pages ซึ่งให้บริการโดย GitHub เมื่อคุณเข้าชม GitHub อาจได้รับข้อมูลการเข้าถึงทั่วไป เช่น ที่อยู่ IP เวลาที่ส่งคำขอ และข้อมูลเบราว์เซอร์ เพื่อให้บริการและปกป้องเว็บไซต์ หน้าเว็บเหล่านี้ไม่มีสคริปต์วิเคราะห์ โฆษณา หรือแบบอักษรและรูปภาพที่โหลดจากภายนอก ดูคำชี้แจงความเป็นส่วนตัวของ GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

ผลงานส่วนตัวและฉบับร่างจะคงอยู่จนกว่าคุณจะลบ การล้างข้อมูลแอปหรือถอนการติดตั้งจะลบข้อมูลส่วนตัวของแอป รวมถึงค่ากำหนดในเครื่องและบันทึกการยืนยัน โปรดเก็บต้นฉบับและไฟล์ที่ส่งออกซึ่งจำเป็นไว้ก่อน

ไฟล์ชั่วคราวสำหรับการแก้ไข การถ่ายภาพ และการพิมพ์จะถูกล้างระหว่างขั้นตอนการใช้งานปกติ การหยุดชะงักหรือแอปขัดข้องอาจทำให้การล้างล่าช้า ไฟล์แคชสำหรับการแชร์จะเข้าเกณฑ์ลบได้หลังเจ็ดวัน แต่การล้างจะทำงานเมื่อคุณแชร์ครั้งถัดไป ดังนั้นไฟล์อาจคงอยู่นานกว่านั้น Google เก็บข้อมูลที่จัดเก็บโดยบริการของตนตามกฎที่ใช้กับแต่ละบริการ การลบแอปไม่ได้ทำให้ข้อมูลนั้นถูกลบเสมอไป ดูข้อมูลความเป็นส่วนตัวของ Firebase เพิ่มเติม: https://firebase.google.com/support/privacy

Google บริการอีเมล และบริการโฮสต์เว็บไซต์อาจประมวลผลข้อมูลนอกประเทศของคุณ มาตรการคุ้มครองที่ใช้บังคับขึ้นอยู่กับบริการและกฎหมาย และอาจรวมถึงกลไกการโอนตามสัญญาหรือกลไกอื่นที่ได้รับการยอมรับ ติดต่อเราเพื่อขอข้อมูลที่มีเกี่ยวกับการประมวลผลที่เราเป็นผู้รับผิดชอบ นโยบายของ Google อธิบายการจัดการข้อมูลระหว่างประเทศของตน

11. กลุ่มผู้ใช้และรูปภาพของผู้อื่น

แอปนี้มีไว้สำหรับผู้ใหญ่และไม่ได้มุ่งให้เด็กใช้งาน ผู้ใหญ่จะสร้างรูปภาพให้เด็กได้ต่อเมื่อมีอำนาจที่จำเป็นในฐานะพ่อแม่ ผู้ปกครอง หรืออำนาจอื่นตามกฎหมาย หากคุณเชื่อว่าเด็กให้ข้อมูลแก่เราโดยไม่มีอำนาจหรือการอนุญาตที่เหมาะสม โปรดติดต่อเราเพื่อให้เราประเมินคำขอและดำเนินการตามความเหมาะสม

ใช้รูปภาพของบุคคลอื่น รวมถึงรูปภาพเด็ก เฉพาะเมื่อได้รับอนุญาตและได้รับความยินยอมจากพ่อแม่หรือผู้ปกครองตามที่กฎหมายที่ใช้บังคับกำหนด

12. การเปลี่ยนแปลงนโยบายนี้

เราจะอัปเดตนโยบายนี้เมื่อแนวปฏิบัติที่เกี่ยวข้องเปลี่ยนไป และระบุเวอร์ชันที่อัปเดต การเปลี่ยนแปลงที่สำคัญจะมีการแจ้งอย่างเด่นชัด หากจำเป็น เราจะขอความยินยอมใหม่ก่อนการประมวลผลที่ได้รับผลกระทบ การเปิดนโยบายนี้เพียงอย่างเดียวจะไม่เปลี่ยนตัวเลือกที่คุณบันทึกไว้
