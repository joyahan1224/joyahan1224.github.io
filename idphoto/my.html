ဓာတ်ပုံတည်းဖြတ်ခြင်း၊ မျက်နှာတည်နေရာ သတ်မှတ်ခြင်းနှင့် နောက်ခံဖယ်ရှားခြင်းတို့ကို သင့်စက်ပေါ်တွင် လုပ်ဆောင်သည်။ ဓာတ်ပုံများကို တည်းဖြတ်ဝန်ဆောင်မှုသို့ မတင်ပို့သလို ကြော်ငြာရှင်များထံလည်း မပို့ပါ။ မျက်နှာတည်နေရာ သတ်မှတ်ခြင်းသည် ဓာတ်ပုံဖွဲ့စည်းမှုကို ကူညီပေးခြင်းသာဖြစ်ပြီး ကလောက်စနစ်ရှိ လူပုဂ္ဂိုလ် အထောက်အထားခွဲခြားသည့် ဝန်ဆောင်မှု မဟုတ်ပါ။

Android ဓာတ်ပုံရွေးချယ်ကိရိယာသည် ရွေးထားသည့် ဓာတ်ပုံများကိုသာ အသုံးပြုခွင့်ပေးသည်။ စက်အဟောင်းများတွင် စက်တွင်းအယ်လ်ဘမ်များ ပြရန် ပုံများကို အသုံးပြုခွင့် တောင်းနိုင်သည်။ ဓာတ်ပုံရိုက်သောအခါ ကင်မရာအသုံးပြုခွင့် တောင်းမည်ဖြစ်ပြီး သင်အတည်ပြုသည့် ပုံကိုသာ တည်းဖြတ်ရန် သုံးသည်။ Android ဆက်တင်များတွင် ခွင့်ပြုချက်များကို ငြင်းပယ် သို့မဟုတ် ရုပ်သိမ်းနိုင်ပြီး သက်ဆိုင်ရာလုပ်ဆောင်ချက်ကို ကန့်သတ်သွားနိုင်သည်။

3. စက်တွင်းဖိုင်များနှင့် ရွေးချယ်သတ်မှတ်ချက်များ

တည်းဖြတ်မှုကို ပြန်ဆက်နိုင်ရန် သီးသန့်လက်ရာများနှင့် မူကြမ်းများတွင် မူရင်းထည့်သွင်းဖိုင်၊ ဖောက်ထွင်းမြင်ရမှုအပါအဝင် ပုံအလွှာများနှင့် တည်းဖြတ်မှတ်တမ်းကို သိမ်းထားနိုင်သည်။ ထည့်သွင်းဖိုင်များကို ဘိုက်တစ်ခုချင်းစီ တိတိကျကျ ကူးယူပြီး မူရင်းတွင် တည်နေရာပါရှိပါက ၎င်းအပါအဝင် ဖိုင်တွင်းမြှုပ်နှံထားသည့် မက်တာဒေတာများ ကျန်ရှိနိုင်သည်။ ဤဖိုင်များကို Android အက်ပ်အရန်သိမ်းဆည်းမှုမှ ဖယ်ထုတ်ရန် သတ်မှတ်ထားသော အက်ပ်သီးသန့်သိုလှောင်နေရာတွင် ထားသည်။ လက်ရာအဟောင်းများတွင် အပြီးသတ်ပုံသာ ပါနိုင်သည်။

အက်ပ်သည် စက်တွင်းမှတ်တမ်း၊ ရွေးချယ်သတ်မှတ်ချက်များ၊ အသိပေးချက်ဗားရှင်းများနှင့် အတည်ပြုချိန်များကိုလည်း သိမ်းသည်။ စက်တွင်းစစ်ဆေးရှာဖွေရေး အချက်အလက်များသည် ချို့ယွင်းမှုများကို စုံစမ်းရန် ကူညီပေးသည်။ အက်ပ်က ဤစက်တွင်းမှတ်တမ်းများကို အလိုအလျောက် မပို့ပါ။

4. သင်ထုတ်ယူ သို့မဟုတ် မျှဝေသည့် မိတ္တူများ

ဓာတ်ပုံပြခန်းသို့ သိမ်းခြင်း၊ ဖိုင် သို့မဟုတ် PDF ထုတ်ယူခြင်း၊ မျှဝေခြင်းနှင့် ပုံနှိပ်ခြင်းတို့သည် မူရင်းဓာတ်ပုံကို အစားမထိုးဘဲ သင်ရွေးချယ်သောနေရာများတွင် သီးခြားမိတ္တူများ ဖန်တီး သို့မဟုတ် ပို့ဆောင်သည်။ လက်ခံအက်ပ်များ၊ သိုလှောင်မှုဝန်ဆောင်မှုပေးသူများနှင့် ပုံနှိပ်ဝန်ဆောင်မှုများသည် ထိုမိတ္တူများကို မိမိတို့မူဝါဒများအတိုင်း ကိုင်တွယ်သည်။ ဓာတ်ပုံပြခန်း သို့မဟုတ် ရည်မှန်းနေရာက ၎င်းတို့ကို ကလောက်စနစ်သို့ တစ်ပြေးညီချိတ်ဆက်သိမ်းဆည်းနိုင်သည်။ အက်ပ်၏ သီးသန့်ဒေတာကို ဖျက်ခြင်းသည် ထိုမိတ္တူများကို မဖျက်ပါ။ ၎င်းတို့ရှိရာနေရာတွင် စီမံပါ။

5. Google ၏ ပြင်ဆင်သတ်မှတ်မှုနှင့် ကြော်ငြာဝန်ဆောင်မှုများ

အက်ပ်၏ အသိပေးချက်ကို သင်အတည်ပြုပြီးနောက် Firebase Remote Config နှင့် Firebase Installations တို့သည် ကြော်ငြာဆက်တင်များ ရယူရန် Google သို့ ချိတ်ဆက်သည်။ ကြော်ငြာပိတ်ထားချိန်တွင်လည်း ချိတ်ဆက်သည်။ ၎င်းတို့က Firebase ထည့်သွင်းမှုအမှတ်အသား၊ ထည့်သွင်းမှုအထောက်အထားစိစစ်ရေး အချက်အလက်၊ စက်၏ ဒေသဆိုင်ရာဆက်တင်မှ နိုင်ငံ သို့မဟုတ် ဒေသကုဒ်၊ ဘာသာစကား၊ အချိန်ဇုန်၊ ပလက်ဖောင်း၊ လည်ပတ်မှုစနစ်၊ အက်ပ်အမှတ်အသား၊ အက်ပ်နှင့် တည်ဆောက်မှုဗားရှင်း၊ ပက်ကေ့ချ်အမည်နှင့် SDK ဗားရှင်းအချက်အလက်များကို ပို့သည်။ ဒေသဆိုင်ရာဆက်တင်မှ ဒေသကုဒ်သည် GPS တည်နေရာ မဟုတ်ပါ။

ကြော်ငြာဝန်ဆောင်မှုများ လုပ်ဆောင်ချိန်တွင် Google AdMob သည် IP လိပ်စာများ၊ IP မှ ခန့်မှန်းသည့် အနီးစပ်ဆုံးတည်နေရာ၊ အက်ပ်နှင့် ကြော်ငြာအပေါ် တုံ့ပြန်လုပ်ဆောင်မှုများ (ဥပမာ အက်ပ်ဖွင့်ခြင်း၊ ကြော်ငြာနှိပ်ခြင်းနှင့် ဗီဒီယိုကြည့်ခြင်း)၊ စွမ်းဆောင်ရည်နှင့် ပြဿနာရှာဖွေရေးဒေတာ၊ Android ကြော်ငြာအမှတ်အသားနှင့် App Set ID ကဲ့သို့ သက်ဆိုင်သော အမှတ်အသားများကို စီမံလုပ်ဆောင်နိုင်သည်။ Google က ဤအချက်အလက်ကို ကြော်ငြာ၊ ခွဲခြမ်းစိတ်ဖြာမှုနှင့် လိမ်လည်မှုတားဆီးရေးအတွက် အသုံးပြုသည်။ ဤ SDK ချိတ်ဆက်မှုများသည် ပို့ဆောင်စဉ် TLS ကုဒ်ဝှက်စနစ်ကို သုံးသည်။

Google UMP သည် သက်ဆိုင်ရာဒေသ၏ ကိုယ်ရေးအချက်အလက်ဆိုင်ရာ ရွေးချယ်မှုများကို စီမံပြီး ထိုရွေးချယ်မှုများကို သဘောတူညီချက်ဖောင်များ တောင်းယူပြသရန် လိုအပ်သည့် အက်ပ်၊ စက်နှင့် တောင်းဆိုမှုအချက်အလက်တို့နှင့်အတူ စီမံလုပ်ဆောင်သည်။ ဤဗားရှင်းတွင် အကောင့်၊ အက်ပ်တွင်းဝယ်ယူမှု၊ စာရင်းသွင်းမှု၊ Firebase Analytics၊ Firebase Crashlytics သို့မဟုတ် Meta SDK မပါပါ။ သို့သော် AdMob သည် ၎င်း၏ကိုယ်ပိုင် ခွဲခြမ်းစိတ်ဖြာမှုကို လုပ်ဆောင်သည်။ Google မူဝါဒတွင် ၎င်း၏ကိုင်တွယ်မှုနှင့် ထိန်းသိမ်းမှုကို ရှင်းပြထားသည်- https://policies.google.com/privacy

6. သင့်ကြော်ငြာရွေးချယ်မှုများ

သက်ဆိုင်သောလုပ်ဆောင်ပုံများ ပြောင်းလဲလျှင် ဤမူဝါဒကို မွမ်းမံပြီး မွမ်းမံထားသည့်ဗားရှင်းကို ဖော်ပြမည်။ အရေးပါသောပြောင်းလဲမှုများကို ထင်ရှားစွာအသိပေးမည်။ လိုအပ်လျှင် သက်ရောက်သည့်စီမံလုပ်ဆောင်မှုမတိုင်မီ သဘောတူညီချက်အသစ် တောင်းမည်။ ဤမူဝါဒကို ဖွင့်ကြည့်ရုံဖြင့် သင်သိမ်းထားသောရွေးချယ်မှုများ မပြောင်းပါ။
